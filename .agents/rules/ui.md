# UI Rules

PixelForge is a creative desktop tool.

Prioritize:

- fast interaction
- visual feedback
- minimal dialogs
- keyboard shortcuts
- drag and drop
- dark workspace
- large preview
- obvious device status

Primary actions should be visually clear:

OPEN
DRAW
CONVERT
SEND
PLAY
EXPORT

Avoid making the application look like an IDE.

The OLED preview should always show the actual logical resolution relationship.

A user should understand what will appear on the physical OLED before sending it.
