---
description: # New Feature Workflow
---



1. Identify the feature.
2. Find the relevant specification.
3. Inspect existing implementation.
4. Define data/API changes.
5. Implement core logic.
6. Add tests.
7. Connect UI.
8. Run build.
9. Test manually if hardware is involved.
10. Update documentation/specification.

Do not implement future features simply because they may be useful.

Keep scope limited to the requested feature.
